# Company domain endpoints

Live contract: `GET https://api.kingminos.com/openapi.yaml` (also `/openapi.json`). REST and hosted MCP (`https://mcp.kingminos.com`) share the Bearer tool inventory. Trimmed copy of the pack map (`api` skill `references/endpoints.md`); `npm run validate` keeps these rows matching it.

## REST ↔ tools

| REST | Tool id (OpenAPI operationId) | Access | Owner / notes |
| --- | --- | --- | --- |
| `POST /v1/company/domain` | `company_domain` | R | Trusted domain stamp + account aliases. Stamp when trusted outcome (`verified` / `corrected` / `discovered` → `es_decision: hit`), non-blank `result.company_domain`, and `answer.confidence` meets path/`min_confidence` ([guidance](https://api.kingminos.com/v1/recipes/guidance)); `rejected` → `reject`; `unverified` → `miss`. Paths `speed` \| `balance` (default) \| `accuracy` \| `coverage`; legacy `fast`/`value`/`name_only` → `speed`, `auto` → `balance`; env `coverage` is ignored. ZoomInfo is BYOK; `builtwith_credentials_required` on coverage without a key. Disagreeing domain/email/website is adjudicated, not a 400. Cache ~5 min per tenant; `X-Router-Cache: bypass` / `skip_cache` skips the read. **Aliases:** `additional_domains` / `additional_domains_csv` are ownership-proven write-safe hosts plus, when the input HTTP-redirects to a different registrable domain and identity passes, that live redirect target (proof `redirect` in `additional_domain_proofs`); never the input host. HubSpot `hs_additional_domains` ← join; SFDC `Secondary_Domains__c` ← `additional_domains_csv`. CRM flows that preserve the entered primary: keep `input_domain` on the primary field; store redirect targets in secondary aliases only. `additional_domains_status` is sweep completeness, not write safety. |
