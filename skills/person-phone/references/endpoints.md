# Person phone endpoints

Live contract: `GET https://api.kingminos.com/openapi.yaml` (also `/openapi.json`). REST and hosted MCP (`https://mcp.kingminos.com`) share the Bearer tool inventory. Trimmed copy of the pack map (`api` skill `references/endpoints.md`); `npm run validate` keeps these rows matching it.

## REST ↔ tools

| REST | Tool id (OpenAPI operationId) | Access | Owner / notes |
| --- | --- | --- | --- |
| `POST /v1/person/phone` | `person_phone` | R | One dialable phone number for a person, plus the ranked rest (`person.phone`). `email` or `linkedin_url` required (top level or under `person`; neither → `400 validation_failed` / `email_or_linkedin_required`); `first_name` / `last_name` are match-only (reject someone else's profile → `person_mismatch`), never infer. `phone_types` filter (`mobile` \| `landline` \| `other` \| `unknown`; omit = any) + `max_results` (1–10, default 3). `format` (`e164` default \| `international` \| `national` \| `digits` \| `digits_national`) picks the `number` string. `result.best_phone` / `result.phones[]` entries: `number`, `e164`, `formats`, `country_code`, `calling_code`, `type`, `line_type`, `source`, `sources`, `confidence`, `flags`, `safe_to_write`; phones ranked safe-first then mobile, deduped, filter-honoring; invalid, junk, not-direct-dial and switchboard numbers dropped (free libphonenumber + location checks); `result.flags` (`conflicting_numbers`, `numbers_dropped`). Agent-managed router (default): plans per request from the input (email / LinkedIn / name+domain) and region, fans out a parallel wave of free-on-miss vendors (ZoomInfo BYOK, LeadMagic, AI Ark, Findymail US-only), scores vendor agreement (`consensus`: unanimous / majority / single / conflict; `do_not_call` when the vendor says), and escalates to Wiza only on a miss, a conflict, or early for non-US. `routing.path` = speed (cap 10) / balance (default) / accuracy / coverage; `routing.only` / `ignore` filter the pool. Only the vendors behind best_phone bill, capped at 38 credits; 0 on a miss; BYOK 0.1. 30-day cache keyed on the filter (`skip_cache` / `X-Router-Cache: bypass`; replay 0 credits); stamp only when `answer.safe_to_write.best_phone`. API tenants only. → `person-phone`. |
