# Person phone endpoints

Live contract: `GET https://api.kingminos.com/openapi.yaml` (also `/openapi.json`). REST and hosted MCP (`https://mcp.kingminos.com`) share the Bearer tool inventory. Trimmed copy of the pack map (`api` skill `references/endpoints.md`); `npm run validate` keeps these rows matching it.

## REST ↔ tools

| REST | Tool id (OpenAPI operationId) | Access | Owner / notes |
| --- | --- | --- | --- |
| `POST /v1/person/phone` | `person_phone` | R | One dialable phone number for a person, plus the ranked rest (`person.phone`). `email` or `linkedin_url` required (top level or under `person`; neither → `400 validation_failed` / `email_or_linkedin_required`); `first_name` / `last_name` are match-only (reject someone else's profile → `person_mismatch`), never infer. `phone_types` filter (`mobile` \| `landline` \| `other` \| `unknown`; omit = any) + `max_results` (1–10, default 3). `format` (`e164` default \| `international` \| `national` \| `digits` \| `digits_national`) picks the `number` string. `result.best_phone` / `result.phones[]` entries: `number`, `e164`, `formats`, `country_code`, `calling_code`, `type`, `line_type`, `source`, `sources`, `confidence`, `flags`, `safe_to_write`; phones ranked safe-first then mobile, deduped, filter-honoring; invalid, junk, not-direct-dial and switchboard numbers dropped (free libphonenumber + location checks); `result.flags` (`conflicting_numbers`, `numbers_dropped`). Agent-managed router, answers in < 10 s: every eligible vendor (ZoomInfo / QuickEnrich / Blitz BYOK, LeadMagic, AI Ark, Findymail US-only, Wiza) runs in parallel under a ~8.5 s budget; late vendors are dropped (bill 0). Four modes via `routing.path`: `speed` (cheapest vendors, first number, cap 10, never Wiza), `balance` (default: best single number by vendor prior / region / line type, no waiting for agreement), `accuracy` (agreement required; `conflicting_numbers` → not safe), `coverage` (up to 5 ranked numbers, each with source, line type, confidence, consensus). `consensus` and `do_not_call` on every number; `routing.only` / `ignore` filter the pool. Only vendors behind returned numbers bill (coverage: each returned number), capped at 38 credits; 0 on a miss; BYOK 0.1. 30-day cache keyed on the filter (`skip_cache` / `X-Router-Cache: bypass`; replay 0 credits); stamp only when `answer.safe_to_write.best_phone`. API tenants only. → `person-phone`. |
