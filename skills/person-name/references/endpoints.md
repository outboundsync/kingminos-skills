# Person name endpoints

Live contract: `GET https://api.kingminos.com/openapi.yaml` (also `/openapi.json`). REST and hosted MCP (`https://mcp.kingminos.com`) share the Bearer tool inventory. Trimmed copy of the pack map (`api` skill `references/endpoints.md`); `npm run validate` keeps these rows matching it.

## REST ↔ tools

| REST | Tool id (OpenAPI operationId) | Access | Owner / notes |
| --- | --- | --- | --- |
| `POST /v1/person/name` | `person_name` | R | A person's cleaned, proper-cased first / last / full name (`person.name`). `email` or `linkedin_url` required (top level or under `person`; neither → `400 validation_failed` / `email_or_linkedin_required`; bad URL → `invalid_linkedin_url`); `phone` / `x_handle` are accepted but never looked up (phone- or X-only → `unsupported_input`, 0 credits). Salutations, honorifics, suffixes, pronouns, emoji and URLs stripped; a judge splits only ambiguous multi-word names on `balance` and above and never invents one. `answer.outcome` `resolved` (hit) \| `parsed_only` (low-confidence email local-part guess, flag `email_local_parse`, never billed) \| `role_address` (shared mailbox, 0 credits) \| `conflict` (sources or identifiers disagree, flag `conflicting_names`, 0 credits) \| `not_found` (`zero_hits` \| `person_mismatch` \| `below_min_confidence`; `result.person` null) \| `unsupported_input`. `result.first_name`, `result.last_name`, `result.full_name`, `result.name_source` (`vendor` \| `email_local_parse`), `result.matched_on`, `result.email_type` (`role` \| `freemail` \| `work`), `result.flags`, `result.evidence` (below-floor candidates). `routing.path` `speed` \| `balance` (default) \| `accuracy` \| `coverage` — outcome-priced 1 / 2 / 3 / 5 credits on a hit, 0 on a miss, conflict or withhold; `routing.only` / `ignore` honored. Confidence is the only write signal (no `safe_to_write`): default floors speed / coverage `low`, balance `medium`, accuracy `high`; `min_confidence` overrides; below the floor the name fields are blank. 30-day cache (`skip_cache` / `X-Router-Cache: bypass`; replay 0 credits). `451 subject_suppressed` at 0 credits. API tenants only. → `person-name`. |
